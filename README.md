# Motion to Command

## Challenge 9 - Y-HACK'26

A low-cost wearable hand-gesture control system
for controlling a robotic device wirelessly.

## Hardware(robot)
- Arduino uno
- MPU6050
- 3 Flex Sensors
- nRF24L01
- L298N
- DC Motors

## Features
- Forward / Reverse control
- Left / Right control
- Speed control
- Deadman safety mechanism
- Wireless communication
